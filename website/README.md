# HAAG Website - Multi-Page Site

This is a professional multi-page website for the HAAG research initiative. The site is built with HTML, CSS, and vanilla JavaScript with no external dependencies.

## Files Included

### HTML Pages
- **index.html** - Home page with overview and quick CTA cards
- **case-study.html** - Charleston Trains case study in detail
- **partnerships.html** - Partnership models and process
- **opportunities.html** - Directory of partnership opportunities
- **faq.html** - Comprehensive FAQ section
- **contact.html** - Contact information and forms

### Supporting Files
- **styles.css** - Shared stylesheet for all pages
- **script.js** - Navigation and TOC functionality

## Features

✓ Multi-page site with navigation menu across all pages
✓ Sticky navigation bar that shows which page you're on
✓ Table of Contents on relevant pages (sticky sidebar)
✓ Professional design with academic/civic tech aesthetic
✓ Fully responsive - works great on mobile, tablet, desktop
✓ No external dependencies - just HTML, CSS, and vanilla JS
✓ Fast loading
✓ Accessible - semantic HTML, proper heading hierarchy

## Customization

To adapt this for your needs:

1. Replace placeholder text: [your email], [Name, Title], [Building, Room #]
2. Update colors: Edit CSS variables in styles.css (:root section)
3. Add/remove pages: Create new HTML files with the same structure
4. Change fonts: Update Google Fonts imports in each HTML file

## How to Use

1. Download all files to a folder
2. Open index.html in a web browser
3. All navigation links will work locally or on a web server

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge)

## Mobile Responsive

The site is fully responsive with optimized layouts for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)

The TOC sidebar hides on smaller screens to save space.

## Typography

- Body: Source Sans Pro (sans-serif) - clean, readable
- Fonts loaded from Google Fonts CDN
